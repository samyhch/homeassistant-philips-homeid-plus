# Philips HomeID Plus

Unified, unofficial Home Assistant support for compatible Philips HomeID appliances, Pet Series feeders, air purifiers, and humidifiers.

The first release includes tested Pet Series support for PAW3320/02 and PAW5320/02, plus local encrypted-CoAP support adapted from the Philips AirPurifier CoAP project.

This project is based on and credits:

- [Philips HomeID](https://github.com/renaudallard/homeassistant_philips_homeid)
- [Philips Pet Series](https://github.com/AboveColin/HA-Philips-Pet-Series)
- [Philips AirPurifier CoAP](https://github.com/kongo09/philips-airpurifier-coap)

See the README before migrating an existing device from another integration.
